# Симулятор GPIO STM32F427VGT6

Модель реализует регистры GPIO из RM0090, §8.4: `MODER`, `OTYPER`,
`OSPEEDR`, `PUPDR`, `IDR`, `ODR`, `BSRR`, `LCKR`, `AFRL`, `AFRH`. Размер
регистров — 32 бита, полезны 16 выводов. Прерывания и настройка тактирования
намеренно исключены из области моделирования.

`GPIOPort.read(offset)` и `GPIOPort.write(offset, value)` — интерфейс
микроконтроллера к регистрам. `Simulator.schedule_input(time, port, pin,
level)` программирует внешний уровень `0`, `1` или `None` (Z) на заданный
момент модельного времени. `advance_to()` доставляет такие события.

## Запуск

Из этого каталога:

```bash
python3 demo_garland.py
python3 -m unittest -v
```

Первый запуск создаёт `garland.log`. Это сценарий, близкий к варианту 2
лабораторной: PC15 настроен как вход с pull-up, PD13/14/15 — выходы для
зелёного, жёлтого и красного светодиодов. Два запланированных активных-низким
уровнем нажатия кнопки переключают режимы гирлянды. В журнале есть все
операции чтения/записи регистров, смены входа и видимые уровни светодиодов.

`BSRR` изменяет `ODR` атомарно: младшие 16 бит устанавливают, старшие 16
сбрасывают соответствующие биты. `IDR` отражает физический уровень: состояние
внешней линии, подтяжки, либо драйвера выхода; для open-drain логическая единица
освобождает линию.
